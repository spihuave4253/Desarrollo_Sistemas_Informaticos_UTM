# API RESTful - Help Desk Data Center

Backend para la gestión de tickets del sistema de Help Desk.

## Instalación

1. Clona el repositorio y navega a la carpeta "backend".

Adicionalmente crear un archivo .env con la URI de MongoDB junto con el puerto para establecer la conexion con la base de datos
En mi caso son:
MONGO_URI=mongodb+srv://spihuave4253_db_user:8CQ9xtHZ9PfQ1fZD@cluster0.5csi7p8.mongodb.net
PORT=5000

2. Instalar las dependencias

npm install
